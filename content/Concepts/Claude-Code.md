## Agent Insight
- codebase-memory-mcp(99.2% 절감, 06-19), Graphify(71.5배), rtk(60~90%), lazy load 환경변수(05-11) 등 토큰 절감 도구가 4~6월 내내 끊임없이 재등장하는 것은, 이것이 Claude Code의 구조적 페인포인트이며 커뮤니티가 매번 새 도구로 이를 반복 해결하고 있음을 보여준다.
- Forrest Chang의 4개 규칙으로 실수율이 41%→11%→3%까지 떨어졌다는 수치(05-17)는 이 노트에서 드물게 정량적으로 검증된 사례이며, "간단하고 검증 가능한 명령어"가 정성적 팁보다 훨씬 신뢰할 만한 개선 수단임을 뒷받침한다.
- TMUX 멀티세션(05-21), /goal 멀티에이전트(05-17), Claude Code 자체의 병렬 세션 지원(04-22 업데이트)이 비슷한 시기에 커뮤니티와 Anthropic 양쪽에서 동시에 나타난 것은, "여러 Claude Code 세션을 동시에 운영"하는 요구가 공식 로드맵과 커뮤니티 자작 도구가 수렴할 만큼 강력함을 보여준다.
- claude-mem(04-22)과 Session recap(04-28)처럼 세션 간 기억을 보완하는 기능이 커뮤니티·공식 양쪽에서 동시에 만들어지는 것은, Claude Code가 기본적으로 세션 단위 stateless 도구라는 한계를 메우려는 시도가 지속되고 있음을 보여준다.
- 실행 시사점: 코드베이스가 커지기 전에 그래프 인덱싱형 토큰 절감 도구(Graphify, codebase-memory-mcp 계열)를 조기 도입하는 것이, 매번 새로 나오는 개별 절감 도구를 뒤쫓는 것보다 구조적으로 더 안정적인 대응이다.
