## Agent Insight
- 2026년 3월~4월 사이, Anthropic(Claude Code Agent Teams), OpenAI(Workspace Agents), Cursor(클라우드 에이전트), 커뮤니티(OhMy Codex, 채팅방 협업) 모두 동시다발적으로 "멀티 에이전트 협업" 프레임을 내놓았다 — 단일 에이전트에서 팀 단위 오케스트레이션으로 업계 전체가 이동하는 궤적.
- 협업 방식이 두 갈래로 갈린다: 하향식 거버넌스(회사 보안 정책·프로젝트 규칙·개인 규칙 계층화, n_1_jjjin)와 상향식 자율 소통(채팅방에서 @멘션으로 컨텍스트 복붙 없이 대화하는 방식, softdaddy_o) — 통제와 자율성 사이의 트레이드오프가 드러난다.
- 팀 규모 확대는 토큰 비용 폭증이라는 대가를 수반하고(lian.lab71), 자동화는 KPI 합의 없이는 오히려 불신을 낳는다(marketer.ai.seulki) — "에이전트를 더 붙이면 더 나아진다"는 가정이 실제로는 비용·신뢰 붕괴로 이어질 수 있음을 시사.
- Cursor의 영상 데모(병합 PR의 3분의 1이 클라우드 에이전트 산출물)와 OhMy Codex의 24시간 10만 스타는 멀티 에이전트 협업이 이미 실무 비중을 차지하기 시작했다는 증거다.
- 실행 시사점: 팀 기능을 도입할 때 처음부터 규모를 키우기보다 핵심 메시지만 전달하는 소규모 팀 + 계층화된 규칙(보안/프로젝트/개인)으로 시작해 토큰 비용과 신뢰 붕괴 리스크를 동시에 관리할 것.
