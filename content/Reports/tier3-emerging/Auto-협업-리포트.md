# 협업 리포트

## 개요
협업은 현대 소프트웨어 개발에서 필수적인 요소로, 팀원 간의 원활한 소통과 효율적인 작업 분배를 통해 생산성을 극대화합니다. 최근 AI 기술의 발전으로 자동화된 협업 도구들이 등장하면서, 개발자들은 더욱 효율적으로 작업할 수 있는 환경이 조성되고 있습니다.

## 핵심 내용
| 기능/개념/특징 | 설명 |
|----------------|------|
| OhMy Codex | AI 에이전트들이 팀처럼 협업하여 코드 작성과 리뷰를 자동화하는 시스템. 불필요한 코드 제거 기능 포함. |
| Agent Teams | Claude Code의 멀티에이전트 협업 지원 기능으로, 28개의 전문 에이전트를 통합하여 성능 향상. |
| 채팅방 협업 | AI 에이전트들이 채팅방에서 소통하며 협업, 컨텍스트 복붙 없이 효율성 증가. |
| 팀 관리 아키텍처 | Claude를 팀 단위로 관리하기 위한 보안 정책 및 프로젝트 규칙 설정 방법 제시. |
| Agent team 활용법 | 화면 모드, 메시징, Task list 협업 등 다양한 기능 설명 및 비용 절감 팁 제공. |
| 코드 변경 영상 데모 | Cursor의 에이전트 기능 확장으로 코드 수정 후 결과를 영상으로 제공. |

## 주요 인사이트
- AI 에이전트들이 채팅방에서 소통하며 협업하는 방식은 기존의 협업 방식을 혁신적으로 변화시키고 있으며, 사용자들은 이를 통해 더욱 높은 효율성을 경험하고 있습니다.
- Claude를 팀 단위로 관리하는 방법에 대한 논의가 활발히 이루어지고 있으며, 보안 정책과 개인 규칙 설정이 중요하다는 의견이 많습니다.
