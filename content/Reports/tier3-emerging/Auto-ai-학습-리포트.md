# AI 학습 리포트

## 개요
AI 학습은 인공지능 기술의 발전과 함께 점점 더 중요해지고 있습니다. 특히, 자동화 및 데이터 수집 기술의 발전은 다양한 산업에서 효율성을 높이고 있으며, 사용자 맞춤형 솔루션을 제공하는 데 기여하고 있습니다.

## 핵심 내용
| 기능/개념/특징 | 설명 |
|----------------|------|
| 레코드 & 리플레이 | OpenAI의 Codex에 추가된 기능으로, 사용자가 작업을 시연하면 AI가 이를 학습하여 반복 작업을 자동으로 수행. 현재 macOS에서만 사용 가능. |
| 무료 학습 자료 | 오픈AI, 구글, 앤트로픽 등에서 제공하는 다양한 무료 자료들이 유용하다는 점 강조. 추천 콘텐츠 18개 소개. |
| 웹사이트 크롤링 API | Cloudflare가 오픈 베타로 출시한 API 엔드포인트로, AI 학습 데이터 수집에 최적화. 콘텐츠 크리에이터에게 저작권 침해 우려를 초래. |
