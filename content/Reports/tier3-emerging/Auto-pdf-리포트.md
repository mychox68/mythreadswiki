# PDF 관련 트렌드 리포트

## 개요
PDF는 다양한 분야에서 널리 사용되는 문서 형식으로, 데이터 추출 및 변환 기술의 발전이 중요해지고 있습니다. 최근 오픈소스 도구와 AI 기술의 결합으로 PDF의 활용도가 더욱 높아지고 있으며, 이는 비즈니스 및 연구 분야에서 효율성을 크게 향상시킬 수 있습니다.

## 핵심 내용
| 기능/개념/특징 | 설명 |
|----------------|------|
| 한컴 오픈데이터로더 PDF v2.0 | PDF를 AI가 읽을 수 있는 데이터로 변환, 상업적 사용 무료, GitHub 트렌딩 1위 |
| 비정형 PDF 데이터 추출 | 오픈소스 파싱 프로그램을 통해 PDF를 JSON으로 변환, XYCut을 활용한 OCR 전처리 |
| NotebookLM PDF 변환 도구 | PDF를 PPTX로 변환, Gemini API 활용, 텍스트 좌표 정확하게 추출 |
| opendataloader-pdf 라이브러리 | PDF에서 구조화된 데이터 추출, LLM 학습 데이터 준비 및 문서 자동화에 유용 |
