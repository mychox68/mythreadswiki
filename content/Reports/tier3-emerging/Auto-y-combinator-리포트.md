# Y Combinator 리포트

## 개요
Y Combinator는 스타트업 생태계에서 중요한 역할을 하는 액셀러레이터로, 최근 AI 기술과의 융합을 통해 혁신적인 솔루션을 제공하고 있습니다. 특히, Garry Tan CEO가 공개한 gstack과 같은 도구들은 소프트웨어 개발의 효율성을 극대화하고, AI 기반 자동화 시스템을 통해 새로운 비즈니스 모델을 제시하고 있습니다.

## 핵심 내용
| 기능/개념/특징 | 설명 |
|----------------|------|
| gstack | Claude Code 기반의 커스텀 명령어 세트로, 12개의 슬래시 명령어로 구성되어 다양한 소프트웨어 개발 기능을 지원 |
| 자동화 시스템 | Naive 서비스는 AI가 스스로 회사를 운영하며, 독립적인 AI 직원이 다양한 업무를 수행 |
| 오픈소스 | gstack은 MIT 라이선스로 공개되어 팀원과 쉽게 공유 가능 |
| 작업 효율성 | Garry Tan은 gstack을 통해 60일 동안 60만 줄의 프로덕션 코드를 작성 |

## 최신 동향
- **2026-03-27**: Y Combinator CEO Garry Tan이 Claude Code 기반의 gstack을 오픈소스로 공개했습니다. 이 도구는 다양한 소프트웨어 개발 역할을 지원하며, AI의 활용도를 높이고 있습니다.

## 주요 인사이트

- Naive 서비스는 AI가 독립적으로 운영하는 기업 모델을 제시하며, 창업자들에게 새로운 기회를 제공합니다.
