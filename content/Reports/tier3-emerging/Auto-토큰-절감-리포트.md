# 토큰 절감 리포트

## 개요
토큰 절감은 AI 및 프로그래밍 환경에서 비용 효율성을 높이는 중요한 주제입니다. 특히 대형 코드베이스와 복잡한 프로젝트에서 토큰 사용량을 줄이는 것은 개발자들에게 큰 도움이 될 수 있습니다.

## 핵심 내용
| 기능/개념               | 설명                                                                                   |
|----------------------|--------------------------------------------------------------------------------------|
| **codebase-memory-mcp** | - 코드베이스 탐색 효율성을 향상<br>- 토큰 사용량 99.2% 절감<br>- 158개 언어 지원<br>- 제로 의존성 설치 용이성 |
| **code-review-graph**   | - 수정 시 영향을 받는 파일만 수용<br>- 변경 영향 범위 시각화<br>- 평균 8.2배 토큰 절감<br>- 23개 언어 지원, MIT 오픈소스 |
| **LSP 활성화**         | - Claude Code 사용 시 토큰 소모 문제 해결<br>- LSP 설정으로 75% 절감 효과 가능                        |
