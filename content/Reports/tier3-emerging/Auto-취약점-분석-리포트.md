# 취약점 분석 리포트

## 개요
취약점 분석은 사이버 보안의 핵심 요소로, 시스템의 약점을 식별하고 이를 통해 공격을 방지하는 데 중요한 역할을 합니다. 최근 자동화된 도구와 AI 기술의 발전으로 취약점 분석의 효율성이 크게 향상되고 있으며, 이는 보안 실무자들에게 필수적인 기술로 자리 잡고 있습니다.

## 핵심 내용
| 기능/개념/특징 | 설명 |
|----------------|------|
| **hackingtool** | 네트워크 스캔 및 취약점 분석을 위한 오픈소스 도구로, 보안 실무의 진입 장벽을 낮춤. |
| **Shannon** | AI 기반의 자율 웹 앱 펜테스터로, OWASP 주요 취약점을 높은 성공률로 커버하며, 빠른 결과 제공. |
| **리스크 분석** | 앱 보안 취약점 검사 시 API 키 노출 리스크를 평가하고, 유효한 리스크 분석의 중요성을 강조. |
