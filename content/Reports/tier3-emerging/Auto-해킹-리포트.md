# 해킹 트렌드 리포트

## 개요
해킹은 정보 보안의 핵심 이슈로, 기술 발전과 함께 그 형태와 방법이 변화하고 있습니다. 최근 AI 기술의 발전과 함께 해킹의 위험성 또한 증가하고 있어, 이에 대한 경각심과 예방 조치가 필요합니다.

## 핵심 내용
| 주제 | 핵심 내용 |
|------|------------|
| AI 해킹 | 앤트로픽의 미토스 모델은 AI 해킹 능력을 극대화하여 경제와 보안의 패러다임을 변화시킬 잠재력을 지님. |
| 보안 실수 | 보안 연구소 조사 결과, 앱의 절반이 해킹 가능성이 있으며, RLS 설정 오류, Rate Limit 미설정, API 키 부적절 저장이 주요 원인. |
| 유튜브 해킹 | 2단계 인증을 했음에도 불구하고 협업 관련 메일 클릭으로 유튜브 채널 해킹 피해 발생. |
| 악성 코드 배포 | AI API 통합 라이브러리 'litellm' 해킹으로 악성 코드가 배포되어 오픈소스 프로젝트에 영향. |
| 정보 유출 | LiteLLM 패키지에 악성 코드가 심어져 API 키 등 중요 정보 유출 가능성 발생. |
| 유튜버 채널 복구 | 해킹된 유튜브 채널을 지인의 도움으로 복구한 사례. |
