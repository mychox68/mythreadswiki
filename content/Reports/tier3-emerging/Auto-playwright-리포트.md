# Playwright 리포트

## 개요
Playwright는 웹 브라우저 자동화 도구로, 다양한 웹 애플리케이션의 테스트 및 자동화를 지원합니다. 이 기술은 개발자들이 반복적인 작업을 효율적으로 수행할 수 있도록 도와주며, 특히 웹사이트 제어, 스크린샷, 가격 모니터링 등 다양한 활용이 가능합니다.

## 핵심 내용
| 기능/특징           | 설명                                                         |
|---------------------|--------------------------------------------------------------|
| 웹사이트 제어       | Playwright를 통해 웹사이트의 요소를 클릭하거나 입력할 수 있습니다. |
| 스크린샷 기능      | 웹 페이지의 스크린샷을 쉽게 캡처할 수 있습니다.               |
| 가격 모니터링      | 특정 웹사이트의 가격 변동을 자동으로 모니터링할 수 있습니다.   |
| Codex CLI 통합     | Codex CLI를 통해 Playwright MCP 스킬을 설치하여 활용할 수 있습니다. |
| 다양한 브라우저 지원| Chromium, Firefox, WebKit 등 여러 브라우저에서 작동합니다.     |
