# 하네스 리포트

## 개요
하네스는 AI 개발 및 자동화 분야에서 중요한 역할을 하고 있는 기술로, 특히 에이전트의 성능 향상과 팀 구성에 효과적입니다. 최근의 발전은 하네스를 활용한 다양한 접근법과 도구들이 등장하고 있어, 개발자와 기업들이 이 기술을 통해 효율성을 극대화할 수 있는 기회를 제공합니다.

## 핵심 내용
| 기능/개념/특징 | 설명 |
|----------------|------|
| **성능 개선** | 하네스를 사용하여 Claude Code와 Codex에서의 성능을 개선하는 방법을 제시. |
| **에이전트 기억 저장** | 오픈소스 '하네스'를 통해 AI 에이전트의 기억 저장을 세밀하게 제어 가능. |
| **자동 팀 구성** | Claude Code 기반의 하네스 플러그인을 통해 자동으로 에이전트 팀을 구성하는 기능 제공. |
| **템플릿 제공** | 100개의 실전용 템플릿을 제공하여 사용자가 쉽게 적용할 수 있도록 지원. |
