# Next.js 트렌드 리포트

## 개요
Next.js는 현대 웹 개발에서 중요한 역할을 하고 있는 프레임워크로, 서버 사이드 렌더링(SSR)과 정적 사이트 생성(SSG) 기능을 제공합니다. 최근 AI와의 통합 및 보안 문제에 대한 논의가 활발히 이루어지고 있어, 개발자와 기업 모두에게 주목받고 있습니다.

## 핵심 내용
| 기능/개념 | 설명 |
|-----------|------|
| 서버 사이드 렌더링 (SSR) | 페이지를 요청할 때 서버에서 HTML을 생성하여 클라이언트에 전달. |
| 정적 사이트 생성 (SSG) | 빌드 시 미리 HTML 파일을 생성하여 빠른 로딩 속도 제공. |
| API 라우팅 | API 엔드포인트를 쉽게 생성할 수 있는 기능. |
| 이미지 최적화 | 자동으로 이미지를 최적화하여 성능 향상. |
| TypeScript 지원 | TypeScript를 통한 정적 타입 검사 지원. |
