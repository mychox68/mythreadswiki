# npm 트렌드 리포트

## 개요
npm은 JavaScript 생태계에서 가장 널리 사용되는 패키지 관리자입니다. 최근 공급망 공격과 같은 보안 이슈가 증가함에 따라, npm의 안전한 사용과 관리 방법에 대한 논의가 활발히 이루어지고 있습니다. 이러한 배경 속에서 npm의 최신 동향과 주요 인사이트를 이해하는 것은 개발자와 기업 모두에게 중요합니다.

## 핵심 내용
| 기능/개념/특징 | 설명 |
|----------------|------|
| 공급망 공격 대응 절차 | 오염 진단, 즉시 차단, 자격증명 로테이션 체크리스트 생성 등의 단계 포함 |
| Mini Shai-Hulud 공격 | npm 생태계에서 발생한 치명적인 공급망 공격으로, 버전 고정 및 점검 도구 사용 권장 |
| 소스코드 유출 문제 | Claude Code의 소스코드가 NPM에서 유출되었으며, 배포 전 파일 목록 검증 필요성 강조 |
| AI 에이전트 'gws' | Google Workspace API에 접근 가능한 AI 에이전트로, npm을 통해 설치 가능 |

## 주요 인사이트
- 공급망 공격에 대한 경각심이 높아지면서, npm 사용자들은 API 키와 토큰의 로테이션을 필수적으로 고려해야 한다는 의견이 많음.
- 배포 과정에서의 실수로 인한 소스코드 유출 사건은 개발자들에게 배포 전 검증의 중요성을 다시 한번 일깨워줌.
- AI 에이전트의 도입은 npm 생태계에 새로운 기회를 제공하며, 자동화 SaaS 시장에 큰 영향을 미칠 것으로 예상됨.
