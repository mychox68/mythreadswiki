# NotebookLM 리포트

## 개요
NotebookLM은 콘텐츠 제작, 회의록 작성, 학습 등 다양한 분야에서 AI를 활용하여 효율성을 극대화하는 도구입니다. 특히, 자동화된 워크플로우와 프롬프트 기능을 통해 사용자들이 시간과 노력을 절약할 수 있도록 돕고 있습니다.

## 핵심 내용
| 기능/특징      | 설명                                                                                   |
|----------------|----------------------------------------------------------------------------------------|
| 콘텐츠 분석    | 유튜브 채널 분석 및 콘텐츠 제작을 위한 다양한 프롬프트 제공                           |
| 회의록 자동화  | 회의 녹음을 요약하고 액션 아이템을 추출하여 자동으로 회의록 생성                     |
| 자료 기반 콘텐츠| Gemini와 연결하여 자료를 기반으로 한 콘텐츠 생성 및 확장 가능                        |
| 학습 지원      | 학습 자료를 업로드하고 질문을 통해 지적 지형도를 완성하여 학습 효과 극대화            |
| PDF 변환       | PDF 파일을 PPTX로 변환하여 발표 자료로 재가공 가능                                   |
| 프롬프트 세트  | 다양한 작업을 자동화하여 전문가 수준의 분석과 통찰을 빠르게 제공                     |
| 리서치 자동화  | Claude Code와 Notion을 연동하여 리서치 및 콘텐츠 기획 자동화                         |
