# 웹 스크래핑 리포트

## 개요
웹 스크래핑은 데이터 수집의 효율성을 높이고, 다양한 웹사이트에서 정보를 자동으로 추출할 수 있는 기술입니다. 최근에는 웹 스크래핑과 관련된 다양한 도구와 기술들이 등장하여, 데이터 분석 및 비즈니스 인사이트 도출에 중요한 역할을 하고 있습니다.

## 핵심 내용
| 기능/개념/특징 | 설명 |
|----------------|------|
| Scrapling | 아카마이 방화벽을 우회하여 크롤링을 가능하게 하는 파이썬 기반 오픈소스 프로젝트 |
| Bright Data API | 프록시를 통해 안전하게 데이터를 수집하고, LLM이 활용하기 좋게 구조화 가능 |
| Playwright | 브라우저 자동화 작업을 수행할 수 있는 도구로, 웹사이트 제어 및 가격 모니터링 기능 제공 |
| Scrapi.ai | 마크다운 형식으로 스크래핑할 수 있는 도구, 첫 가입 시 5달러 크레딧 제공 |
