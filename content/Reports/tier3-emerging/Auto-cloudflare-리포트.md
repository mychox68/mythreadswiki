# Cloudflare 리포트

## 개요
Cloudflare는 웹사이트 보안 및 성능 최적화 솔루션을 제공하는 플랫폼으로, 최근 다양한 기능과 서비스를 통해 개발자와 사용자에게 큰 주목을 받고 있습니다. 특히, 서버리스 CMS와 웹 크롤링 API의 출시 등은 웹 개발 환경에 혁신적인 변화를 가져오고 있습니다.

## 핵심 내용
| 기능/개념/특징 | 설명 |
|----------------|------|
| EmDash | Cloudflare가 인수한 Astro를 기반으로 한 PHP 없는 서버리스 오픈소스 CMS. TypeScript로 재설계되어 플러그인 샌드박스를 지원. |
| 개인 도메인 이메일 | Cloudflare를 통해 Gmail에서 무료로 개인 도메인 이메일을 사용할 수 있는 방법. 소규모 사용자에게 적합. |
| 웹사이트 크롤링 API | Cloudflare가 오픈 베타로 출시한 /crawl API 엔드포인트. AI 학습 데이터 수집에 최적화되어 있으며, 저작권 침해 우려가 제기됨. |
| Claude Code 통합 | Claude Code에서 Cloudflare의 /crawl 엔드포인트를 활용하여 웹사이트 크롤링이 가능. RAG 파이프라인 및 모델 학습용 데이터 수집에 유용. |
