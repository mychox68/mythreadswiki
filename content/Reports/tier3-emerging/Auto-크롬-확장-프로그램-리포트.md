# 크롬 확장 프로그램 리포트

## 개요
크롬 확장 프로그램은 웹 브라우저의 기능을 확장하고 사용자 경험을 개선하는 도구로, 다양한 분야에서 활용되고 있습니다. 최근의 트렌드는 디자인 추출, 파일 뷰어, 이미지 다운로드 등으로, 이들 도구는 사용자에게 효율성을 제공하고 있습니다.

## 핵심 내용
| 확장 프로그램 이름              | 주요 기능 및 특징                                                                 |
|----------------------------------|----------------------------------------------------------------------------------|
| DESIGN.md Style Extractor        | - 웹사이트의 스타일 구조를 추출<br>- AI 코딩 에이전트와 연동 가능<br>- 로그인 필수 페이지 및 로컬 개발 환경 지원 |
| Markdown Viewer                   | - .md 파일을 드래그 앤 드롭으로 볼 수 있음<br>- 양식 적용 상태로 미리보기 제공<br>- md2pdf.netlify.app을 통한 PDF 변환 기능 |
| Gemini Voyager                    | - 워터마크 없이 이미지 다운로드 가능<br>- 인터랙티브 타임라인 탐색<br>- 스마트 폴더 관리자 및 프롬프트 라이브러리 제공 |

## 최신 동향
- **2026-04-22**: DESIGN.md Style Extractor가 소개됨. 웹사이트의 디자인 구조를 쉽게 추출할 수 있는 기능이 강조됨. [🔗 원문](https://www.threads.com/@choi.openai/post/DXWZ9wOj7l4)
- **2026-03-27**: Markdown Viewer와 Gemini Voyager가 각각 소개됨. Markdown Viewer는 .md 파일을 쉽게 볼 수 있는 기능을 제공하며, Gemini Voyager는 이미지 다운로드 기능을 포함한 다양한 유용한 기능을 제공함. [🔗 원문](https://www.threads.com/@saemidoc/post/DWJmqdDgXy9), [🔗 원문](https://www.threads.com/@thestack_ai/post/DVcvA74DwVH)

## 주요 인사이트
- 사용자들은 크롬 확장 프로그램을 통해 디자인 시스템을 손쉽게 가져오고, 파일 형식에 구애받지 않고 다양한 작업을 수행할 수 있는 방법을 찾고 있습니다.
- Gemini Voyager는 특히 Gemini 사용자들에게 유용한 도구로, 워터마크 제거와 같은 기능이 큰 관심을 받고 있습니다.
