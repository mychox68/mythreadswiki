# 마크다운 리포트

## 개요
마크다운은 간단한 텍스트 형식으로 문서를 작성할 수 있게 해주는 경량 마크업 언어입니다. 최근 AI와 디자인 시스템의 통합이 증가하면서, 마크다운의 중요성이 더욱 부각되고 있습니다. 특히, 디자인 시스템을 마크다운으로 표준화함으로써 AI가 UI를 보다 일관되게 생성할 수 있는 기반이 마련되고 있습니다.

|----------------|------|

| Google Stitch | DESIGN.md 개념을 도입하여 디자인 시스템을 표준화, LLM이 UI를 생성하는 데 도움. |
| HTML 노이즈 제거 | AI가 웹사이트 정보를 더 정확하게 추출할 수 있도록 마크다운 변환 방법 제공. |
| Claude Code와 Obsidian 연동 | 로컬 마크다운 파일에 직접 접근하여 효율적인 노트 관리 가능. |

- 마크다운을 활용한 디자인 시스템의 표준화는 AI가 디자인 의도를 보다 명확하게 이해하고 구현할 수 있도록 돕습니다.
- HTML 노이즈를 제거하는 방법은 AI의 정보 추출 능력을 향상시키며, 마크다운 형식이 이를 지원하는 데 중요한 역할을 합니다.
