# 멀티 에이전트 리포트

## 개요
멀티 에이전트 시스템은 AI 에이전트 간의 협업과 효율적인 작업 분배를 가능하게 하여, 다양한 분야에서의 혁신을 이끌고 있습니다. 이러한 시스템은 특히 복잡한 작업을 수행하는 데 있어 필수적인 도구로 자리잡고 있으며, 향후 AI의 발전 방향에 큰 영향을 미칠 것으로 기대됩니다.

## 핵심 내용

| 기능/개념/특징 | 설명 |
|----------------|------|
| 멀티 에이전트 관리 | Claude Code의 최신 버전에서 추가된 기능으로, 여러 세션을 효율적으로 관리할 수 있음. |
| 독립적인 프로필 | Hermes에서 각 프로필이 독립적인 환경을 제공하여 격리된 에이전트를 운영 가능. |
| 병렬 작업 처리 | Claude Code의 /ultraplan 기능을 통해 클라우드에서 계획을 병렬로 생성. |
| ACP(Agent Client Protocol) | acpx에서 다양한 에이전트 간의 호환성을 높이는 표준 프로토콜. |
| 에이전트 팀 구성 | 여러 Claude Code를 팀으로 묶어 작업을 분배하고 협업 가능. |
| 문맥 비대증 방지 | AI 에이전트 활용 시 명확한 지시 및 종료 조건 설정 필요. |
