# LLM 모델 동향 리포트

## 개요
LLM(대형 언어 모델)은 인공지능 분야에서 혁신적인 변화를 이끌고 있으며, 다양한 산업에서 활용되고 있습니다. 이 리포트는 LLM 모델의 최신 동향과 기능, 그리고 커뮤니티에서의 논의 내용을 정리하여, 관련 기술의 발전 방향을 이해하는 데 도움을 주고자 합니다.

## 핵심 내용
| 기능/개념/특징 | 설명 |
|----------------|------|
| Jev 모델 | 문장 생성과 판단을 분리하여 효율적인 선택지를 제시 |
| SkillOpt 도구 | Codex·Claude의 작업 기록을 활용하여 수정안 생성 및 검증 |
| LLM과 SQL 결합 | 데이터 처리 방식 변화 및 비즈니스 모델 통찰 제공 |
| edit tool | 기존 LLM 모델에 추가하여 성능 향상 |
| Claude Code의 Workflow | AI 작업을 코드로 저장하고 반복 가능 |
| Codex SDK | API 호출 비용 무료화 및 인증 용이성 제공 |
| CCS (Claude Code Switch) | 다양한 AI 모델 통합 어댑터 |
| GPT의 이미지 활용 | 개인화된 보고서 생성 가능성 |
| AGENTS.md 관리 | 코딩 에이전트 성능에 영향 미침 |
| OpenVizAI | 데이터셋과 프롬프트 입력으로 자동 차트 선택 |
