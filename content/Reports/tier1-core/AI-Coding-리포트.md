# AI 코딩 — Vibe Coding·에이전트 코딩 흐름 리포트

## 개요
AI 코딩은 소프트웨어 개발의 효율성을 높이고, 개발자와 AI 간의 협업 방식을 혁신하는 중요한 기술입니다. 최근 AI 코딩 도구와 에이전트의 발전은 개발자들이 더욱 창의적이고 생산적으로 작업할 수 있는 환경을 제공합니다.

## 핵심 내용
| 기능/개념/특징 | 설명 |
|----------------|------|
| **Spec Kit** | 스펙 정의 및 자동 질문을 통해 코드 개발의 명확성을 높임. |
| **ChatGPT 코드인터프리터** | 사용자가 자신의 컴퓨터를 ChatGPT에 연결하여 AI 코딩 에이전트로 활용 가능. |
| **Grok Build** | 마우스 클릭 지원 등 새로운 작업 방식을 제공하는 코딩 에이전트. |
| **Vibe Coding** | 구글의 새로운 개발 방식으로, context engineering과 AI 코딩 에이전트 통합 방법을 다룸. |
| **Claude Code** | 대규모 코드베이스에서 AI 코딩의 효율성을 높이는 다양한 전략 제공. |
| **DESIGN.md** | AI 에이전트를 위한 디자인 시스템을 마크다운 파일 형식으로 제공. |
| **MCP 서버** | Claude Code 사용자를 위한 필수 서버 목록과 기능 설명. |
| **acpx** | 여러 코딩 에이전트를 통합 관리하는 툴로, 협업 효율성을 높임. |

## 주요 인사이트
- **스펙 작성의 중요성**: 요구사항의 품질이 결과에 미치는 영향이 크며, 사전 스펙 작성이 필수적이라는 의견이 다수 공유됨.
- **AI와 협업**: 비개발자도 AI를 활용해 코딩할 수 있는 방법에 대한 논의가 활발히 이루어짐.
- **디자인 자동화**: AI 코딩 도구에 디자인 뇌를 이식하여 UI/UX 디자인을 자동화하는 방법이 주목받고 있음.
