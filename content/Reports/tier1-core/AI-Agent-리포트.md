# AI 에이전트 리포트

## 개요
AI 에이전트는 다양한 작업을 자동화하고 효율성을 높이는 데 중요한 역할을 하고 있습니다. 최근의 기술 발전과 함께 AI 에이전트의 구조와 기능이 혁신적으로 변화하고 있으며, 이는 기업과 개인의 작업 방식에 큰 영향을 미치고 있습니다.

## 핵심 내용
| 기능/개념/특징 | 설명 |
|----------------|------|
| 에이전트 아키텍처 최적화 | 시스템 프롬프트는 필요한 정보만 포함해야 하며, 서브 에이전트는 꼭 필요할 때만 사용하는 것이 이상적입니다. |
| 자동 문서 업데이트 | Claude의 'Routines' 기능을 활용하여 AI 에이전트가 문서를 자동으로 업데이트합니다. |
| Terminal Threads 기능 | Zed 에디터가 터미널과 에이전트를 동일한 사이드바에서 사용할 수 있게 합니다. |
| Ralph Loop 패턴 | 코딩 에이전트가 목표를 설정하고 달성하는 과정을 자동화합니다. |
| 칸반 보드 관리 | 각 카드의 상태값에 따라 에이전트에게 일을 맡길 준비가 되었는지를 관리합니다. |
| HTML 출력 포맷 | AI 에이전트의 출력 포맷으로 HTML이 가독성과 공유 편의성에서 장점을 가집니다. |
| 새로운 AI 에이전트 스킬 키트 | Google 엔지니어링 원칙을 적용하여 에이전트가 올바른 경로를 선택하도록 돕습니다. |
| 온디바이스 AI | 클라우드와 개인 데이터 처리 경계를 설정하는 중요성을 강조합니다. |
| 자기 도구 생성 | AI 에이전트가 자기 도구를 만들기 시작하면서 자동화 스크립트를 작성하는 시대가 끝나가고 있습니다. |
| 금융 특화 에이전트 템플릿 | 앤트로픽이 금융권을 위한 특화 에이전트 템플릿을 공개했습니다. |
