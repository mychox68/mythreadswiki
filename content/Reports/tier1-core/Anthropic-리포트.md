# Anthropic 리포트

## 개요
Anthropic은 AI 기술의 발전과 함께 중요한 역할을 하고 있는 기업으로, Claude 생태계와 관련된 다양한 기능과 정책을 통해 AI의 활용도를 높이고 있습니다. 최근의 기술 발전은 AI 에이전트의 효율성을 극대화하고, 사용자 경험을 개선하는 데 중점을 두고 있습니다.

## 핵심 내용
| 기능/개념          | 설명                                                         |
|-------------------|------------------------------------------------------------|
| Claude Code       | AI가 수행한 작업을 코드로 저장하고 반복할 수 있는 기능.     |
| Managed Agents     | 에이전트가 세션 간 학습하고 스스로 평가 및 개선할 수 있는 기능. |
| MCP               | AI 에이전트와 외부 시스템 간의 통합을 표준화하는 프로토콜.   |
| Dispatch          | 스마트폰으로 데스크탑 Claude에게 작업을 지시하는 기능.      |
| Channels          | Telegram과 Discord에서 Claude Code를 원격으로 제어할 수 있는 기능. |
| 자동 수정         | AI가 GitHub PR을 모니터링하며 자동으로 오류를 수정하는 기능.  |

## 최신 동향
- **2026-05-11**: Anthropic은 Code with Claude 컨퍼런스에서 Claude Managed Agents의 네 가지 기능을 발표했습니다.
- **2026-04-28**: MCP(Model Context Protocol)를 공개하며 AI 에이전트의 외부 시스템 통합을 표준화했습니다.
- **2026-03-27**: Claude Code의 여러 기능이 업데이트되었으며, Claude AI 무료 강의 11개가 공개되었습니다.

## 주요 인사이트
- Anthropic은 단순한 모델 판매자가 아닌 대규모 임대업자로 변모하고 있으며, 이는 기술 트위터에서 큰 관심을 끌고 있습니다.
- Claude Code의 스킬 활용에 대한 확신 부족을 해결하기 위해 사전 준비의 중요성이 강조되고 있습니다.
- AI 캐릭터 대화 앱 시장이 성장세를 보이고 있으며, 한국 스타트업들이 두각을 나타내고 있습니다.
