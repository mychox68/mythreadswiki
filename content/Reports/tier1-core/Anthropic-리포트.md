# Anthropic 리포트

## 개요
Anthropic은 AI 기술의 발전과 함께 사용자 친화적인 에이전트 생태계를 구축하고 있습니다. Claude Managed Agents와 같은 혁신적인 기능을 통해 사용자들이 AI를 보다 쉽게 활용할 수 있도록 지원하며, 이는 AI 기술의 미래와 경쟁 구도에 중요한 영향을 미치고 있습니다.

## 핵심 내용

| 기능/개념          | 설명                                                         |
|------------------|------------------------------------------------------------|
| Claude Managed Agents | 사용자들이 쉽게 에이전트를 만들 수 있도록 지원하는 기능.               |
| Dispatch          | 스마트폰으로 데스크탑 Claude에게 작업을 지시하는 기능.               |
| Claude Code       | 코드 작성 및 수정, 스킬 활용을 지원하는 플랫폼.                      |
| Channels          | Telegram과 Discord에서 Claude Code를 제어할 수 있는 기능.           |
| Skills            | 65,000개 이상의 스킬을 제공하며, 사용자 워크플로우 자동화 지원.      |
| Anthropic Academy | AI 실무자를 위한 무료 강의 플랫폼, 다양한 맞춤형 강의 제공.          |
| Financial Datasets | 30년치 재무 데이터를 자연어로 분석 및 시각화 가능.                   |
