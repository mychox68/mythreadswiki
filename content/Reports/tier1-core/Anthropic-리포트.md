# Anthropic 리포트

## 개요
Anthropic은 AI 기술의 발전과 에이전트 생태계의 변화에 중요한 역할을 하고 있습니다. Claude Managed Agents와 같은 혁신적인 기능들은 AI의 활용도를 높이고, 사용자 경험을 향상시키는 데 기여하고 있습니다.

## 핵심 내용
| 기능/개념          | 설명                                                                 |
|-------------------|----------------------------------------------------------------------|
| Dreaming          | 에이전트가 세션 사이에 학습하여 과거 세션의 메모리를 활용해 패턴을 추출하는 기능. |
| Outcomes          | 에이전트가 스스로 평가하고 개선할 수 있는 구조를 제공.                 |
| MCP               | AI 에이전트의 외부 시스템 통합을 표준화하는 프로토콜.                  |
| Claude Managed Agents | 사용자들이 쉽게 에이전트를 만들 수 있도록 지원하는 시스템.               |
| Dispatch          | 스마트폰으로 데스크탑 Claude에게 작업을 지시하는 기능.                 |
| Channels          | Telegram과 Discord에서 Claude Code를 원격으로 제어할 수 있는 기능.        |
| 자동 수정         | AI가 GitHub PR을 모니터링하며 자동으로 오류를 수정하는 기능.              |

## 주요 인사이트
- Anthropic은 단순한 모델 판매자가 아닌 대규모 임대업자로 변모하고 있으며, 이는 기술 트위터에서 큰 관심을 끌고 있습니다. 
- 사용자들은 Claude Managed Agents를 통해 에이전트를 쉽게 만들 수 있게 되었으며, 이는 AI 활용의 중요성을 더욱 부각시키고 있습니다.
