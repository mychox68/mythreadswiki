# Anthropic 리포트

## 개요
Anthropic은 AI 기술의 발전과 함께 중요한 역할을 하고 있는 기업으로, Claude 생태계와 관련된 다양한 기능과 정책을 통해 AI의 활용성을 높이고 있습니다. 특히, 사용자 친화적인 인터페이스와 강력한 기능들은 AI 기술의 대중화를 촉진하고 있습니다.

## 핵심 내용

| 기능/개념          | 설명                                                         |
|-------------------|------------------------------------------------------------|
| ELI5 Skill        | 복잡한 개념을 간단하고 시각적으로 설명하는 기능. ChatGPT와의 인터랙티브한 활용 가능. |
| Workflow          | AI 작업을 코드로 저장하여 반복할 수 있는 기능. 6가지 패턴과 사용법 제공. |
| Dreaming          | 에이전트가 세션 간 학습하여 과거 세션의 메모리를 활용하는 기능. |
| MCP               | AI 에이전트와 외부 시스템 통합을 표준화하는 프로토콜. 200개 이상의 서버 지원. |
| Claude Managed Agents | 사용자들이 쉽게 에이전트를 만들 수 있도록 지원하는 기능. |
| Dispatch          | 스마트폰으로 데스크탑 Claude에게 작업을 지시하는 기능. |
| 자동 수정 기능    | GitHub PR을 모니터링하고 자동으로 오류를 수정하는 기능. |
| Channels          | Telegram과 Discord에서 Claude Code를 원격으로 제어할 수 있는 기능. |

- Anthropic의 다양한 기능들은 사용자들이 AI를 더 쉽게 활용할 수 있도록 돕고 있으며, 특히 Claude Managed Agents와 같은 기능은 개발자들에게 큰 관심을 받고 있습니다.
