# Anthropic 리포트

## 개요
Anthropic은 AI 기술의 발전과 함께 중요한 역할을 하고 있는 기업으로, Claude 생태계를 중심으로 다양한 기능과 정책을 개발하고 있습니다. 이러한 기술들은 AI의 활용도를 높이고, 사용자 경험을 개선하는 데 기여하고 있습니다.

## 핵심 내용

| 기능/개념/특징 | 설명 |
|----------------|------|
| Claude Code | AI가 수행했던 작업을 코드로 저장하여 반복할 수 있는 기능. |
| Workflow | Claude Code의 숨겨진 기능으로, 6가지 패턴과 사용법 정리. |
| Managed Agents | 에이전트가 세션 사이에 학습하고 스스로 평가 및 개선할 수 있는 기능. |
| MCP (Model Context Protocol) | AI 에이전트의 외부 시스템 통합을 표준화하여 사용자 경험 향상. |
| Dispatch | 스마트폰으로 데스크탑 Claude에게 작업을 지시하는 기능. |
| Channels | Telegram과 Discord에서 Claude Code 세션을 원격으로 제어하는 기능. |
| 자동 수정 기능 | AI가 GitHub PR을 모니터링하며 자동으로 오류를 수정. |
| Skills | 65,000개 이상의 스킬을 정리한 사이트와 함께 생산성 극대화 방법 제공. |

## 주요 인사이트
- Anthropic은 단순한 모델 판매자가 아닌 대규모 임대업자로 변모하고 있으며, 이는 기술 트위터에서 큰 관심을 끌고 있습니다.
- Claude Code의 자동 수정 기능은 개발자의 역할 변화를 가속화할 것으로 예상됩니다.
- 사용자는 Claude Code의 다양한 기능을 통해 생산성을 높이고, AI 활용이 직무 평가에 중요해지는 시대에 대비하고 있습니다.
