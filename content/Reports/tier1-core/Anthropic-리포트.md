# Anthropic 리포트

## 개요
Anthropic은 AI 에이전트와 관련된 혁신적인 기술과 생태계를 구축하고 있습니다. 특히, Claude 생태계와 관련된 다양한 기능과 정책은 AI 업계에서 큰 주목을 받고 있으며, 이는 AI 통합 및 사용자 경험 향상에 기여하고 있습니다.

## 핵심 내용
| 기능/개념/특징 | 설명 |
|----------------|------|
| MCP (Model Context Protocol) | AI 에이전트와 외부 시스템 통합을 표준화하는 프로토콜로, 200개 이상의 MCP 서버 지원. |
| Claude Managed Agents | 사용자들이 손쉽게 AI 에이전트를 만들 수 있도록 지원하는 플랫폼. |
| Dispatch 기능 | 스마트폰으로 데스크탑 Claude에게 작업 지시 가능. |
| Claude Code | 자동 수정 기능 추가로 GitHub PR 모니터링 및 오류 수정 지원. |
| Channels 기능 | Telegram과 Discord에서 Claude Code를 원격으로 제어 가능. |
| Anthropic Academy | 무료 AI 강의 플랫폼으로, 다양한 강의 제공. |

## 최신 동향
- **2026-04-28**: Anthropic이 MCP(Model Context Protocol)를 공개하여 AI 에이전트의 외부 시스템 통합을 표준화함.
- **2026-04-12**: Claude Managed Agents 발표, 사용자들이 에이전트를 쉽게 만들 수 있도록 지원.
- **2026-03-27**: 여러 기능 업데이트 및 무료 강의 플랫폼인 Anthropic Academy 공개.

## 주요 인사이트
- Anthropic의 닫힌 생태계와 경쟁사인 NVIDIA, Google 간의 갈등이 심화되고 있으며, 대체 도구들의 발전이 두드러짐.
- Claude Code의 스킬 활용에 대한 경험 공유가 활발히 이루어지고 있으며, 사전 준비가 스킬 활용 효율을 높이는 데 중요하다는 의견이 많음.
- AI 캐릭터 대화 앱 시장의 성장세와 함께, 한국 스타트업들이 두각을 나타내고 있음.
