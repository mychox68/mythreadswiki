# AI 자동화 리포트

## 개요
AI 자동화는 현대 소프트웨어 개발 및 비즈니스 프로세스에서 필수적인 요소로 자리 잡고 있습니다. 다양한 AI 도구와 플랫폼이 반복적인 작업을 자동화함으로써 효율성을 높이고, 인적 자원의 부담을 줄이는 데 기여하고 있습니다.

## 핵심 내용
| 기능/개념/특징 | 설명 |
|----------------|------|
| GPT Images v2 | 이미지 생성 후 Codex가 이를 분석하여 웹사이트 구현. 디자인 품질이 중요한 프로젝트에 유용. |
| Multica | 오픈소스 AI 개발 플랫폼으로, AI 에이전트를 통해 반복 업무를 처리. TypeScript로 커스터마이징 가능. |
| clawsweeper | 오픈소스 이슈 및 PR 정리를 위한 봇. 50개의 Codex AI를 병렬로 사용하여 이슈를 정리. |
| Codex-sangpye-skill | 제품 상세 페이지 이미지를 자동 생성하는 스킬. OpenAI API 키 없이 ChatGPT 세션 활용 가능. |
| Hermes | Codex를 이용한 이미지 생성 방법 소개. 간단한 커맨드로 설정 가능. |
| Claude Code | '/ultrareview' 기능 추가로 다수의 버그 탐지 에이전트를 클라우드에서 동시에 실행. |
| OpenYak | 로컬에서 작동하는 AI 비서로, 문서 정리 및 데이터 분석 지원. |
| goal-driven-autoresearch-loop | 온라인 테트리스 구현을 위한 자동화 스킬. 성능 향상. |
