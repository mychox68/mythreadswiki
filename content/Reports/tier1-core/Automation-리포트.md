# AI 자동화 리포트

## 개요
AI 자동화는 업무 효율성을 극대화하고 반복적인 작업을 줄이는 데 중요한 역할을 하고 있습니다. 다양한 도구와 기술이 발전하면서, 기업과 개인이 AI를 활용하여 자동화된 시스템을 구축하는 사례가 증가하고 있습니다.

## 핵심 내용
| 기능/개념/특징 | 설명 |
|----------------|------|
| **Aside 브라우저** | 로그인된 웹사이트에서 사용자처럼 작업 수행, 민감한 작업은 사용자 확인 필요 |
| **MiMo Code** | 이미지 이해, 웹 검색, 앱 제작 등 다양한 기능을 지원하는 무료 AI 코딩 도구 |
| **video-use** | 텍스트 기반으로 영상을 편집하는 자동화 툴 |
| **Hermes** | 이메일, 미팅, 데이터 관리를 효율적으로 수행하는 AI 비서 |
| **Codex의 Record & Replay** | 반복 업무를 기록하여 재사용 가능한 스킬로 변환 |
| **Crawl4AI** | 웹사이트 데이터를 자동으로 정리하는 오픈소스 툴 |
| **n8n-MCP** | Slack 메시지 보내기 프롬프트의 설정값을 실시간으로 검증하는 도구 |
