# aside 가 mac에서 다되나??

> [!question] 질문
> aside 가 mac에서 다되나??

## 답변

**1. 네 — Mac에서는 다 됩니다. 애초에 Aside는 macOS 전용입니다.**

Aside(Aside Computer Inc., YC F25, 2026-06-23 출시)는 현재 **macOS에서만 배포**되는 Chromium 포크 기반 AI 에이전트 브라우저입니다. 즉 "Mac에서 되는 기능 / 안 되는 기능"이 나뉘어 있는 게 아니라, Mac이 유일한 지원 플랫폼이고 제품의 모든 기능이 Mac에서 돌아갑니다 (참고: [노트 1], [노트 2]).

**2. Mac에서 쓸 수 있는 것 전부.**

- 브라우저 본체 — 이미 로그인해 둔 사이트(Gmail·Notion·Slack 등) 위에서 에이전트가 사람처럼 클릭·타이핑하며 다단계 작업 수행 (참고: [노트 2], [노트 4]).
- 추론 티어 Low/Medium/High + **Ultrabrowse**(장기 자율 모드) (참고: [노트 1]).
- 개발자 자동화 표면 전부 — **CLI**(`aside "..."`), **MCP 서버**(`aside mcp`, Claude Code에서 연동 가능), **JS REPL**(Playwright 호환 스크립팅), **Skills** (참고: [노트 1], [노트 2]).
- 로컬 우선 저장 + Secure Enclave 암호화, 마크다운 메모리, 에이전트 비밀번호 관리자 (참고: [노트 2]).
- 다운로드 무료이고 모델은 BYO 방식입니다 — 본인 ChatGPT/Claude 구독 연결, 본인 API 키, 또는 Aside 클라우드 크레딧 (참고: [노트 2]).

**3. 반대로 Windows는 아직 안 됩니다.**

제작팀(캐럿 만들었던 팀)이 출시 글에서 직접 "맥 먼저, 윈도우는 제가 더 갈려야 합니다"라고 밝혔습니다. Windows 지원 로드맵은 불명입니다 (참고: [노트 3], [노트 1]). 볼트의 이전 조사에서도 이 macOS 벽 때문에 Windows 환경인 저희 프로젝트(Threads unsave 자동화)에는 권하지 않는다고 결론냈습니다 (참고: [노트 1]).

**4. Mac에서 되긴 하는데, 유의점.**

- 초기 제품이라 버그·성능 이슈 리포트가 있습니다 (참고: [노트 2]).
- 벤치마크 1위 주장(Online-Mind2Web 99% 등)은 자사 채점이고 독립 검증이 없습니다 (참고: [노트 1]).
- "봇 감지·캡챠를 뚫는다"는 이야기는 제작사 주장이며, 밑단이 Playwright/CDP 계열이라 행동 기반 봇 감지·ToS 리스크는 일반 자동화와 동일하다는 게 볼트 조사의 평가입니다 (참고: [노트 1], [노트 3]).
