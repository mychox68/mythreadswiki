# korean-law-mcp 를 찾아봐줘

> [!question] 질문
> korean-law-mcp 를 찾아봐줘

## 답변

**korean-law-mcp**는 대한민국 국가법령정보(법령·판례·조례·조약 등)를 AI가 직접 조회·검색·분석할 수 있게 해주는 무료 오픈소스 MCP 서버입니다.

### 1. 만든 사람과 배경
7년차 지방공무원 `@pjw1962`(GitHub: `chrisryugj`)가 퇴근 후 만든 개인 프로젝트로 소개됐습니다(참고: [노트 2]). 법제처가 제공하는 API를 MCP 도구로 감싸, 헌법·법률·위임법령·행정규칙·자치법규·판례 등 총 175,064건(2026-03-19 기준)을 검색·비교·분석할 수 있습니다.

### 2. 실제 활용 사례 — 정확도 우위
카카오톡 대화방(agent-korea)에서 "전자담배 매장 금연 규정" 질의를 두고 제미나이(범용 LLM)와 클로드+법령 MCP를 비교한 사례가 있습니다(참고: [노트 1]).
- 제미나이: "담배 소매업 지정 매장은 무조건 금연이다" (틀림, 학습 시점 지식으로 단정)
- 클로드+법령 MCP: 시설 규모·지자체 조례·겸업 여부에 따른 조건부 세분화 답변 (실제 조문 근거로 정확)

사용자들은 "법령mcp만세", "실무에 매우 유용" 등으로 반응했고, 정확도가 생명인 법률 도메인에서는 범용 LLM보다 실제 조문을 조회하는 MCP가 훨씬 신뢰할 만하다는 결론이 나왔습니다.

### 3. 기능 발전 흐름 (볼트 기준)
- 2026-03-30: 소개 당시 "39개 법제처 API → 64 tools" (참고: [노트 2])
- 2026-04-08: v3.0 업데이트, "39개 API → 14 MCP 도구"로 재구성, 같은 무료 API 쿼터로 2배 사용 가능하게 개선 (참고: [노트 3])
- Claude Desktop, Cursor, Windsurf, Zed 등 지원, `npm install -g korean-law-mcp` 또는 리모트 엔드포인트로 설치 가능
- MIT 라이선스, 무료

### 4. 사용법 예시
- "지방계약법 제9조 위임법령 3단 비교해줘"
- "개보법 최근 개정 전후 비교"
- "보조금법 별표1 마크다운으로 뽑아줘" (HWPX/HWP 별표도 자동으로 마크다운 표 변환)

## 웹 최신 확인 (2026-07-20)

- 볼트 결론(정확도 우위, 무료 오픈소스)은 유효하나 **도구 구성이 크게 바뀜**. 현재 최신 버전은 **v4.7.4**로, 볼트의 "14 도구/39 API" → **"10개 도구로 42개 API 커버"** 구조로 재편됐고, 검색 정확도·인용 검증 패치와 보안 패치(hono 취약점 5건)가 적용됐습니다.
- 신규 설치 경로로 **Claude Code 플러그인**(`/plugin marketplace add chrisryugj/korean-law-mcp`)이 추가됐고, 원격 커넥터 URL도 `https://mcp.gomdori.app/law?oc=인증키` 형태로 정착됨. 법제처 Open API 인증키(무료)는 여전히 필수. ([GitHub - chrisryugj/korean-law-mcp](https://github.com/chrisryugj/korean-law-mcp))

## 설치 가이드 — Claude Code 플러그인 (2026-07-20, 웹 확인)

**1단계 — 법제처 API 인증키(OC) 발급 (무료, 약 1분)**
1. [법제처 Open API 신청 페이지](https://open.law.go.kr/LSO/openApi/guideList.do) 접속 → 회원가입 후 로그인
2. "Open API 사용 신청" 클릭 → 신청서 작성
3. **API인증키(OC)** 는 서버가 무작위로 발급하는 값이 아니라 **사용자가 직접 원하는 문자열을 지정**하는 방식. "중복확인" 버튼으로 선점 여부만 체크(아이디 만들 때와 동일한 UX). 관례적으로 본인 이메일 `@` 앞부분을 많이 사용.
4. 신청 후 확인은 마이페이지 → API인증키관리 메뉴에서 가능.
5. 이 값은 모든 API 호출의 `OC` 요청변수로 쓰이며, 호출량 제한도 이 값 기준으로 걸림 — 타인에게 공유하면 쿼터를 같이 소모하게 되므로 유출 주의.

**2단계 — Claude Code에서 플러그인 설치**
```
/plugin marketplace add chrisryugj/korean-law-mcp
/plugin install korean-law@korean-law-marketplace
```

**3단계 — API 인증키 등록**
설치 중 "법제처 API 키를 입력하세요" 프롬프트가 뜨면 1단계에서 발급받은 OC 값을 입력. 민감정보로 안전하게 저장됨.

**4단계 — 설치 확인**
채팅창에서 자연어로 바로 테스트.
- "근로기준법 제74조 알려줘"
- "민법 제750조 판례 검증해줘"

AI가 자동으로 `korean-law` MCP 도구를 호출해 조회.
