# 그랜터 API — 개인 계좌 입출금 연동

> [!question] 질문
> "누워있는 죠르디" 님이 개인 계좌 입출금 기록을 연동하고 싶은데 개인은 오픈뱅킹 API 접근이 어렵다고 묻자, "배부른 춘식이" 님이 그랜터 API 활용을 추천(유료)했다. 그랜터 API가 뭔지, 이 추천이 맞는지.

## 결론 (TL;DR)

**"그랜터"를 그대로 가입하는 건 정확한 답이 아니다. 진짜 필요한 건 그랜터가 내부에서 쓰는 CODEF(코드에프)의 개인 계좌조회 API다.**

- **그랜터(Granter)** = granter.biz, 주식회사 그랜터가 만든 **법인·개인사업자 대상 AI 재무회계 SaaS**. 결제내역 자동수집·장부자동화·세금계산서·급여관리까지 딸린 B2B 툴 — 순수 개인이 자기 계좌만 보려고 쓰기엔 과한 제품.
- 그랜터가 계좌·카드 데이터를 가져오는 방식이 **헥토데이터(주)의 코드에프(CODEF) 기술**이라고 공식 명시돼 있음. 즉 "그랜터 API"의 실체는 CODEF다.
- **CODEF(developer.codef.io)**가 죠르디 님 문제의 정확한 답: 오픈뱅킹은 등록된 핀테크 기업만 접근 가능하지만, CODEF는 "개인 빠른조회", "개인 보유계좌", "개인 수시입출 거래내역" API를 **개인용으로 별도 제공**한다.
- 요금은 **종량제**(쓴 만큼만 과금), **3개월간 일 최대 100회 무료 데모** 가능. 다만 "정식 버전" 신청에는 사업자 정보 등록이 요구돼서, 사업자등록 없는 순수 개인이 데모 이후 정식 요금제까지 계속 쓸 수 있는지는 공개 정보로는 불명확. 건당 정확한 단가도 비공개("문의" 형태).
- **결론**: 그랜터(전체 회계 SaaS)에 가입하기보다, **CODEF 개인 계좌조회 API를 직접 붙이는 쪽**이 죠르디 님 목적(개인 입출금 기록 연동)에 더 맞고 불필요한 기능 없이 저렴할 가능성이 높다.

## 그랜터(Granter)란

| 항목 | 내용 |
|---|---|
| 정체 | AI 기반 스타트업/법인 재무회계 솔루션 |
| 대상 | 법인사업자, 개인사업자 (순수 개인 아님) |
| 기능 | 결제내역 실시간 수집, 장부 자동정리, 세금계산서, 전자결재, 급여관리 |
| 데이터 소스 | 헥토데이터(주)의 코드에프(CODEF) 기술 활용 |
| 내보내기 | CSV, 엑셀, 더존 양식 |
| 개발사 | 주식회사 그랜터 (대표 이영인, 사업자 861-86-02839) |
| 요금제 | 페이지에 "무료로 시작하기"는 있으나 구체 가격 비공개 |

## 진짜 답: CODEF(코드에프)

| 항목 | 내용 |
|---|---|
| 정체 | 국내 최대 구독형 금융 데이터 API 중개 플랫폼 (365일 24시간) |
| 개인용 상품 | 개인 빠른조회 API, 개인 보유계좌 API, 개인 수시입출 거래내역 API (은행), 카드 개인 청구내역 API 등 |
| 오픈뱅킹과 차이 | 오픈뱅킹은 등록 핀테크 기업만 접근 가능. CODEF는 개인 개발자도 데모 단계 진입 가능 |
| 무료 데모 | 3개월간 일 최대 100회 API 요청 |
| 정식 전환 | 사업자 정보·프로젝트 정보 등록 후 신청, 승인 시 3영업일 내 도입 |
| 가격 | 종량제(쓴 만큼 과금), 정확한 건당 단가는 비공개 |
| SDK | GitHub에 공식 SDK 존재 (`codef-io/easycodef-java`, `codef-io/easycodefpy` 등) |

## 남은 불확실성

- 사업자등록이 전혀 없는 순수 개인이 데모 기간(3개월/일 100회) 이후에도 CODEF 정식 요금제를 계속 쓸 수 있는지는 공개 문서로 확인 안 됨 — 실제 가입 시도 시 확인 필요.
- CODEF의 정확한 건당 가격은 공개 페이지에 없고 "문의"를 통해서만 확인 가능.
