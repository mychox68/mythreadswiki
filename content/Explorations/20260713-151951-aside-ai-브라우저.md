# Aside — Chromium 기반 AI 에이전트 브라우저

> 2026-06-23 공개 후 X·Threads에서 바이럴된 신생 AI 브라우저. 사실 위주 정리(출처 하단).

## TL;DR
- **Aside Computer Inc.**(YC F25 스타트업)이 만든 **Chromium 기반 AI 에이전트 브라우저**.
- 별도 API 연동 없이, **내가 이미 로그인한 사이트**에서 에이전트가 사람처럼 클릭·타이핑하며 다단계 작업을 대신 수행.
- **CLI · MCP · JS REPL**로 자동화 스크립팅 가능. 밑단은 Playwright/CDP 호환.
- **macOS 전용**, 다운로드 무료(모델은 BYO — 내 ChatGPT/Claude 구독이나 API 키 연결).

## 무엇을 하나
"AI 브라우저"의 의미는 **에이전트가 실제 웹을 사람처럼 조작**한다는 것. 통합(integration) 없이 Gmail·Notion·Slack·Figma 등 **내 로그인 세션 그대로** 위에서 작업을 수행한다.

**핵심 기능**
- 추론 강도 티어 Low/Medium/High + **Ultrabrowse**(장기 자율 모드 — 끝까지 알아서)
- **로컬 우선**: 작업·메모리가 기기에 저장, Secure Enclave 하드웨어 암호화
- **편집 가능한 마크다운 메모리**: 에이전트 기억을 사람이 읽고 고칠 수 있는 md로
- **에이전트 비밀번호 관리자**: AI에 비번을 노출하지 않고 페이지에 자동입력

## 자동화 표면 (개발자용)
소비자 UI 외에 공식 자동화 인터페이스를 제공한다.
- **CLI** — 터미널에서 에이전트 세션 시작 (`aside "..."`, `--session`으로 이어가기)
- **MCP 서버** — `aside mcp` 로 Claude Code 등 다른 에이전트에서 Aside 구동
- **REPL** — `aside repl "..."` 로 JS를 써서 탭 열기·조작·스크린샷 등 **결정적 단계 스크립팅**
- **Skills** — 한 번 가르치면 재생

**내부 구동**(3자 기술분석): 핵심 도구는 JS REPL로 짜는 **Playwright 호환 코드**("Asidewright" = CDP 메서드의 얇은 래퍼), 페이지 상태는 **접근성 트리**로 표현, DOM이 막히면 **비전(스크린샷)+좌표 클릭(CUA)** 폴백, 그래도 막히면 사이트 내부 API 리버스 엔지니어링.

## 냉정한 평가
- **벤치마크 1위 주장**(Online-Mind2Web 99% 등)은 **자사 채점·독립 검증 없음** — 걸러 볼 것.
- **초기 제품**: macOS 전용, 버그·성능 이슈 리포트 있음.
- **"에이전트 브라우저면 봇 감지를 뚫는다"는 오해** — 밑단이 Playwright/CDP라 탐지 표면은 일반 자동화와 동일. 비전+좌표 폴백이 **난독화된 DOM**엔 강하지만, 사이트의 **행동 기반 봇 감지(속도·규칙성)** 나 **ToS 리스크**를 없애주진 않는다. 오히려 내 실제 세션 위에서 돌아 감지 시 **내 계정이 리스크**.

## 비슷한 것들 (혼동 주의)
- 다른 AI 브라우저: **Arc / Dia / Comet(Perplexity) / Atlas** 등 — Aside와 별개 제품.
- **동명이인 오탐**: `aside.dev`(GitHub `alxclark/aside`, DevTools 확장), 크롬 웹스토어 "aside" 사이드패널 확장 — **둘 다 이 AI 브라우저가 아님**.
